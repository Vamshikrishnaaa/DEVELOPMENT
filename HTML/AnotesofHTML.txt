`BLOCK ELEMENTS`
-elements which take up the whole line whose size is same as the elements size
  ex- header , paragraph 

`Inline elements`
elements which only take up as much space as their size 
  ex- anchor tag,image

`Div element <div>`
Content Division element
 -its a block element
 -so any inline elements can be grouped together and 
  made into block element using <div> </div>
  ex- images and links (using anchor tag) are inlines , can be converted into
    block element 

`Span element <span>`
it prevents a block element from occupying a whole line in the page
